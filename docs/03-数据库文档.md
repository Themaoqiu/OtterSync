# OtterSync 数据库文档

## 1. 数据库设计目标

数据库用于支撑 OtterSync 的项目协作、任务流转、工作区权限、AI 辅助、报表归档和通知审计。设计重点是：

- 支持一个用户加入多个工作区。
- 支持工作区下创建多个空间/项目。
- 支持工作项分派、状态流转、工时、测试和历史记录。
- 支持报表、AI 对话、复盘文档归档。
- 支持权限审计和通知追踪。

推荐数据库：MySQL 8。

## 2. 主要实体关系

```text
users 1---N workspace_members N---1 workspaces
workspaces 1---N spaces
spaces 1---N issues
spaces 1---N sprints
sprints 1---N issues
issues 1---N issue_status_history
issues 1---N work_logs
issues 1---N comments
issues 1---N attachments
spaces 1---N reports
users 1---N notifications
users 1---N ai_conversations
ai_conversations 1---N ai_messages
workspaces 1---N audit_logs
```

## 3. 表结构设计

### 3.1 用户表 `users`

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| `id` | bigint | PK | 用户 ID |
| `username` | varchar(64) | unique, not null | 登录名 |
| `display_name` | varchar(64) | not null | 显示名 |
| `email` | varchar(128) | unique | 邮箱 |
| `password_hash` | varchar(255) | not null | 密码哈希 |
| `avatar_url` | varchar(255) | nullable | 头像 |
| `status` | varchar(32) | not null | `ACTIVE`、`DISABLED` |
| `theme_mode` | varchar(16) | nullable | `LIGHT`、`DARK`、`SYSTEM` |
| `created_at` | datetime | not null | 创建时间 |
| `updated_at` | datetime | not null | 更新时间 |

### 3.2 工作区表 `workspaces`

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| `id` | bigint | PK | 工作区 ID |
| `name` | varchar(128) | not null | 工作区名称 |
| `key_code` | varchar(32) | unique, not null | 工作区 Key |
| `description` | text | nullable | 描述 |
| `owner_id` | bigint | FK users.id | 拥有者 |
| `visibility` | varchar(32) | not null | `PRIVATE`、`INTERNAL`、`PUBLIC` |
| `created_at` | datetime | not null | 创建时间 |
| `updated_at` | datetime | not null | 更新时间 |

### 3.3 工作区成员表 `workspace_members`

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| `id` | bigint | PK | 成员记录 ID |
| `workspace_id` | bigint | FK | 工作区 ID |
| `user_id` | bigint | FK | 用户 ID |
| `role` | varchar(32) | not null | `OWNER`、`ADMIN`、`MEMBER`、`VIEWER`、`EXTERNAL` |
| `status` | varchar(32) | not null | `INVITED`、`ACTIVE`、`REMOVED` |
| `joined_at` | datetime | nullable | 加入时间 |
| `created_at` | datetime | not null | 创建时间 |

唯一索引：`uk_workspace_user(workspace_id, user_id)`。

### 3.4 群组表 `groups`

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| `id` | bigint | PK | 群组 ID |
| `workspace_id` | bigint | FK | 工作区 ID |
| `name` | varchar(128) | not null | 群组名称 |
| `visibility` | varchar(32) | not null | `PUBLIC`、`PRIVATE`、`INVITE_ONLY` |
| `description` | text | nullable | 描述 |
| `created_by` | bigint | FK users.id | 创建人 |
| `created_at` | datetime | not null | 创建时间 |

### 3.5 空间/项目表 `spaces`

现有前端用“空间”承载 Jira 风格项目，因此数据库用 `spaces` 表统一表示空间或项目。

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| `id` | bigint | PK | 空间 ID |
| `workspace_id` | bigint | FK | 所属工作区 |
| `name` | varchar(128) | not null | 空间名称 |
| `key_code` | varchar(32) | not null | 空间 Key，如 `OT` |
| `type` | varchar(32) | not null | `SCRUM`、`KANBAN`、`GENERAL` |
| `description` | text | nullable | 描述 |
| `lead_id` | bigint | FK users.id | 负责人 |
| `status` | varchar(32) | not null | `ACTIVE`、`ARCHIVED` |
| `created_at` | datetime | not null | 创建时间 |
| `updated_at` | datetime | not null | 更新时间 |

唯一索引：`uk_workspace_space_key(workspace_id, key_code)`。

### 3.6 工作项表 `issues`

| 字段 | 类型 | 约束 | 说明 |
| --- | --- | --- | --- |
| `id` | bigint | PK | 工作项 ID |
| `space_id` | bigint | FK | 所属空间 |
| `sprint_id` | bigint | FK nullable | 所属 Sprint |
| `issue_key` | varchar(32) | unique, not null | 工作项编号，如 `OT-1` |
| `title` | varchar(255) | not null | 标题 |
| `description` | text | nullable | 描述 |
| `type` | varchar(32) | not null | `TASK`、`BUG`、`STORY`、`EPIC` |
| `status` | varchar(32) | not null | `TODO`、`IN_PROGRESS`、`IN_REVIEW`、`TESTING`、`DONE`、`CANCELED` |
| `priority` | varchar(32) | not null | `HIGHEST`、`HIGH`、`MEDIUM`、`LOW`、`LOWEST` |
| `assignee_id` | bigint | FK nullable | 经办人 |
| `reporter_id` | bigint | FK | 报告人 |
| `due_date` | date | nullable | 截止日期 |
| `estimate_minutes` | int | default 0 | 预估工时 |
| `spent_minutes` | int | default 0 | 已登记工时 |
| `created_at` | datetime | not null | 创建时间 |
| `updated_at` | datetime | not null | 更新时间 |
| `completed_at` | datetime | nullable | 完成时间 |

建议索引：

- `idx_issues_space_status(space_id, status)`
- `idx_issues_assignee_status(assignee_id, status)`
- `idx_issues_due_date(due_date)`
- `idx_issues_updated_at(updated_at)`

| 值 | 中文 |
| --- | --- |

| `IN_PROGRESS` | 进行中 |
| `IN_REVIEW` | 待评审 |
| `TESTING` | 测试中 |
| `DONE` | 已完成 |
| `CANCELED` | 已取消 |

### 优先级

| 值 | 中文 |
| --- | --- |
| `HIGHEST` | 最高 |
| `HIGH` | 高 |
| `MEDIUM` | 中 |
| `LOW` | 低 |
| `LOWEST` | 最低 |

### 工作区角色

| 值 | 中文 | 权限说明 |
| --- | --- | --- |
| `OWNER` | 拥有者 | 全部权限 |
| `ADMIN` | 管理员 | 管理成员、空间、工作项 |
| `MEMBER` | 成员 | 创建和处理工作项 |
| `VIEWER` | 查看者 | 只读 |
| `EXTERNAL` | 外部人员 | 只能访问被分享内容 |

## 5. 数据保留与审计

- 业务数据默认软删除，建议增加 `deleted_at` 字段或状态字段。
- 工作项状态变化必须写入 `issue_status_history`。
- 权限、成员、报表、AI 生成等关键操作必须写入 `audit_logs`。
- 附件、报表文件应保存文件哈希，避免重复上传和便于追踪。
