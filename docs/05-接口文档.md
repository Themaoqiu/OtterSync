# OtterSync 接口文档

## 1. 接口约定

基础路径：

```text
/api/v1
```

认证方式：

```text
Authorization: Bearer <access_token>
```

统一响应：

```json
{
  "code": "OK",
  "message": "success",
  "data": {},
  "traceId": "req-20260422-000001"
}
```

统一分页：

```json
{
  "items": [],
  "page": 1,
  "pageSize": 20,
  "total": 0,
  "hasNext": false
}
```

## 2. 认证接口

### 登录

`POST /auth/login`

请求：

```json
{
  "username": "themaoqiu",
  "password": "password"
}
```

响应：

```json
{
  "accessToken": "xxx",
  "refreshToken": "yyy",
  "expiresIn": 7200,
  "user": {
    "id": 1,
    "displayName": "Themaoqiu",
    "avatarInitials": "MT"
  }
}
```

### 刷新令牌

`POST /auth/refresh`

### 退出登录

`POST /auth/logout`

### 当前用户

`GET /users/me`

用于前端头像、账户中心和全局用户信息。

## 3. 工作区与成员接口

### 获取当前用户工作区

`GET /workspaces`

响应：

```json
[
  {
    "id": 1,
    "name": "OtterSync",
    "key": "OT",
    "role": "OWNER"
  }
]
```

### 创建工作区

`POST /workspaces`

请求：

```json
{
  "name": "OtterSync",
  "key": "OT",
  "visibility": "PRIVATE"
}
```

### 邀请成员

`POST /workspaces/{workspaceId}/members/invitations`

请求：

```json
{
  "email": "member@example.com",
  "role": "MEMBER"
}
```

### 获取成员列表

`GET /workspaces/{workspaceId}/members`

### 更新成员角色

`PATCH /workspaces/{workspaceId}/members/{memberId}`

请求：

```json
{
  "role": "ADMIN"
}
```

## 4. 空间/项目接口

### 空间列表

`GET /spaces?workspaceId=1`

对应前端 `/spaces` 页面。

响应：

```json
[
  {
    "id": 1,
    "name": "ottersync",
    "key": "OT",
    "type": "SCRUM",
    "status": "ACTIVE"
  }
]
```

### 最近查看空间

`GET /spaces/recent`

### 创建空间

`POST /spaces`

请求：

```json
{
  "workspaceId": 1,
  "name": "ottersync",
  "key": "OT",
  "type": "SCRUM",
  "description": "项目协作空间"
}
```

### 空间详情

`GET /spaces/{spaceId}`

### 空间摘要指标

`GET /spaces/{spaceId}/summary`

响应：

```json
{
  "metrics": [
    {
      "headline": "过去 7 天内",
      "value": 0,
      "emphasis": "项已完成",
      "type": "COMPLETED"
    }
  ],
  "statusOverview": [
    {
      "status": "TODO",
      "label": "待办",
      "count": 2
    }
  ],
  "priorityBreakdown": [
    {
      "priority": "MEDIUM",
      "count": 1
    }
  ]
}
```

## 5. 工作项接口

### 工作项列表

`GET /issues`

查询参数：

| 参数 | 说明 |
| --- | --- |
| `workspaceId` | 工作区 ID |
| `spaceId` | 空间 ID |
| `assigneeId` | 经办人 |
| `status` | 状态 |
| `priority` | 优先级 |
| `keyword` | 搜索关键词 |
| `page` | 页码 |
| `pageSize` | 每页数量 |

响应：

```json
{
  "items": [
    {
      "id": 1,
      "key": "OT-1",
      "title": "测试任务1",
      "status": "TODO",
      "priority": "MEDIUM",
      "assignee": {
        "id": 1,
        "displayName": "Themaoqiu",
        "avatarInitials": "MT"
      }
    }
  ],
  "page": 1,
  "pageSize": 20,
  "total": 1,
  "hasNext": false
}
```

### 创建工作项

`POST /issues`

请求：

```json
{
  "spaceId": 1,
  "title": "使用毛球",
  "description": "完成指定功能开发",
  "type": "TASK",
  "priority": "MEDIUM",
  "assigneeId": 1,
  "dueDate": "2026-04-30"
}
```

### 工作项详情

`GET /issues/{issueId}`

### 更新工作项

`PATCH /issues/{issueId}`

请求：

```json
{
  "title": "使用毛球",
  "priority": "HIGH",
  "assigneeId": 2
}
```

### 更新工作项状态

`POST /issues/{issueId}/transitions`

请求：

```json
{
  "toStatus": "IN_PROGRESS",
  "reason": "开始开发"
}
```

### 提交工时

`POST /issues/{issueId}/work-logs`

请求：

```json
{
  "minutes": 120,
  "content": "完成页面联调与单元测试",
  "loggedAt": "2026-04-22T10:00:00+08:00"
}
```

### 获取工作项活动

`GET /issues/{issueId}/activities`

## 6. Sprint 与待办接口

### 获取待办分组

`GET /spaces/{spaceId}/backlog`

对应空间详情“待办事项列表”。

响应：

```json
[
  {
    "id": 1,
    "title": "OT面板 冲刺 1",
    "issueCount": 1,
    "todoCount": 1,
    "inProgressCount": 0,
    "doneCount": 0,
    "items": [
      {
        "id": 2,
        "key": "OT-2",
        "title": "使用毛球",
        "status": "TODO",
        "assigneeInitials": "MT"
      }
    ]
  }
]
```

### 创建 Sprint

`POST /spaces/{spaceId}/sprints`

### 开始 Sprint

`POST /sprints/{sprintId}/start`

### 关闭 Sprint

`POST /sprints/{sprintId}/close`

### 看板数据

`GET /spaces/{spaceId}/board`

响应按状态列返回工作项。

## 7. 筛选器接口

### 默认筛选器

`GET /filters/defaults`

响应：

```json
[
  {
    "id": "my-open",
    "title": "我的未处理工作项",
    "query": {
      "assignee": "me",
      "statusNotIn": ["DONE", "CANCELED"]
    }
  }
]
```

### 我的筛选器

`GET /filters`

### 创建筛选器

`POST /filters`

请求：

```json
{
  "name": "最近创建",
  "query": {
    "createdWithinDays": 7
  }
}
```

### 应用筛选器查询工作项

`GET /issues?filterId=my-open`

## 8. 日历接口

### 获取空间日历事项

`GET /spaces/{spaceId}/calendar?month=2026-04&filter=status`

响应：

```json
[
  {
    "date": "2026-04-14",
    "issueCount": 0,
    "issues": []
  }
]
```

## 9. 仪表板接口

### 仪表板列表

`GET /dashboards`

### 默认仪表板

`GET /dashboards/default`

### 分配给我的工作项

`GET /dashboards/default/assigned-issues`

### 活动流

`GET /dashboards/default/activities`

响应：

```json
[
  {
    "id": 1,
    "text": "maoqiu The 创建了 OT-1 - 测试任务1",
    "issueKey": "OT-1",
    "createdAt": "2026-04-22T08:00:00+08:00"
  }

```

### 成员绩效分析

`GET /dashboards/member-performance?spaceId=1&from=2026-04-01&to=2026-04-30`

### 项目进度分析

`GET /dashboards/progress?spaceId=1`

## 10. 通知接口

### 通知列表

`GET /notifications?page=1&pageSize=20`

响应：

```json
{
  "items": [
    {
      "id": 1,
      "title": "分配给你的工作项已更新",
```

`POST /notifications/{notificationId}/read`

### 全部已读

`POST /notifications/read-all`

## 11. AI 接口

### 主页今日概述

`GET /ai/home-summary`

响应：

```json
{
  "summary": "今天有 2 个待办工作项，暂无到期事项。",
  "sources": [
    {
      "type": "ISSUE",
      "id": 1,
      "title": "测试任务1"
    }
  ]
}
```

### 创建 AI 会话

`POST /ai/conversations`

### 发送消息

`POST /ai/conversations/{conversationId}/messages`

请求：

```json
{
  "content": "帮我查看 ottersync 项目当前进度"
}
```

响应：

```json
{
  "messageId": 10,
  "content": "当前项目共有 2 个工作项，均处于待办状态。",
  "sources": [
    {
      "type": "SPACE",
      "id": 1,
      "name": "ottersync"
    }
  ],
  "confidence": 0.86
}
```

### AI 创建项目或空间建议

`POST /ai/actions/propose`

请求：

```json
{
  "prompt": "创建一个 Scrum 项目，用于移动端开发"
}
```

响应：

```json
{
  "proposalId": 1,
  "actionType": "CREATE_SPACE",
  "preview": {
    "name": "移动端开发",
    "type": "SCRUM"
  }
}
```

### 确认执行 AI 建议

`POST /ai/actions/{proposalId}/confirm`

## 12. 报表接口

### 生成复盘报告

`POST /reports/retrospectives`

请求：

```json
{
  "spaceId": 1,
  "from": "2026-04-01",
  "to": "2026-04-30",
  "template": "DEFAULT"
}
```

响应：

```json
{
  "reportId": 1,
  "status": "GENERATING"
}
```

### 获取报表详情

`GET /reports/{reportId}`

### 导出报表

`GET /reports/{reportId}/export?format=docx`

### 分享报表

`POST /reports/{reportId}/shares`

请求：

```json
{
  "targetEmail": "external@example.com",
  "permission": "VIEW"
}
```

## 13. 反馈接口

### 提交反馈

`POST /feedback`

请求：

```json
{
  "source": "HOME_SUMMARY",
  "rating": "LIKE",
  "content": "摘要有帮助"
}
```

用于主页摘要点赞/点踩、仪表板反馈、账户中心反馈。

## 14. 前端接口映射

| 前端位置 | 操作 | 建议接口 |
| --- | --- | --- |
| 主页头像 | 打开账户 | `GET /users/me` |
| 主页创建按钮 | 创建工作项 | `POST /issues` |
| 主页搜索 | 搜索工作区/事务 | `GET /search` 或 `GET /issues?keyword=` |
| 主页今日概述 | 加载 AI 摘要 | `GET /ai/home-summary` |
| 主页快速访问 | 空间/面板跳转 | `GET /spaces/recent` |
| 空间页 | 获取空间列表 | `GET /spaces` |
| 空间页创建 | 创建空间 | `POST /spaces` |
| 所有工作 | 工作项列表 | `GET /issues` |
| 所有工作筛选 | 默认筛选器 | `GET /filters/defaults` |
| 空间详情摘要 | 指标与图表 | `GET /spaces/{spaceId}/summary` |
| 空间详情待办 | 待办分组 | `GET /spaces/{spaceId}/backlog` |
| 空间详情日历 | 日历事项 | `GET /spaces/{spaceId}/calendar` |
| 仪表板 | 活动流 | `GET /dashboards/default/activities` |
| 通知 | 通知列表 | `GET /notifications` |
| 账户中心退出 | 退出登录 | `POST /auth/logout` |
