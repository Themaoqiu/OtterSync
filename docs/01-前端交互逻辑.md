# OtterSync 前端交互逻辑

## 1. 文档依据

本文档根据现有 Flutter 前端代码、用例描述、业务流程图和数据流图整理。当前前端是移动端原型应用，已完成主要页面、导航、筛选、折叠、主题切换等交互；真实后端接口尚未接入，多个按钮以“接口已预留”的提示方式占位。

已解析资料包括：

- `lib/main.dart`
- `lib/routes/index.dart`
- `lib/pages/**`
- `lib/components/**`
- `lib/viewmodels/jira_demo_data.dart`
- `流程图/OtterSync业务流程（4合一）.pdf`
- `流程图/OtterSync数据流图(new).pdf`
- `流程图/cross_functional_swimlanes.svg`
- `流程图/第2小组-用例图与用例描述.docx`

旧版 `.doc` 文件因本机工具对传统 Word 二进制格式支持有限，未作为本次结构化整理的主要依据。

## 2. 前端技术与运行结构

| 项目 | 内容 |
| --- | --- |
| 框架 | Flutter |
| 语言 | Dart |
| 路由 | `go_router` |
| UI 规范 | Material 3 + 自定义设计令牌 |
| 主题 | 浅色/深色主题，通过 `ThemeController` 全局切换 |
| 当前数据来源 | `JiraDemoData` 静态演示数据 |
| 后端状态 | 尚未接入真实 API，页面中多处提示“接口已预留” |

应用入口为 `main.dart`，仅负责调用 `runApp(getRootWidget())`。根路由、主题、底部导航均在 `routes/index.dart` 中装配。

## 3. 路由与页面结构

| 路由 | 页面 | 说明 |
| --- | --- | --- |
| `/` | 重定向 | 自动跳转到 `/home` |
| `/home` | 主页 | 今日概述、搜索、快速访问、最近项目 |
| `/spaces` | 空间 | 最近查看空间、所有空间、空间搜索和创建入口 |
| `/all-work` | 所有工作 | 工作项筛选、列表/网格视图切换 |
| `/dashboards` | 仪表板 | 默认仪表板、分配给我的工作项、活动流、反馈入口 |
| `/notifications` | 通知 | 通知列表、深浅色主题切换 |
| `/account` | 账户中心 | 用户信息、工作区邀请、通知设置、设置、反馈、退出登录 |
| `/space-details` | 空间详情 | 摘要、面板、日历、表单、待办事项列表 |

底部导航使用 `StatefulShellRoute.indexedStack`，五个主 Tab 在切换时保留页面状态。

## 4. 主导航交互

底部导航包含五个入口：

| Tab | 页面 | 交互逻辑 |
| --- | --- | --- |
| 主页 | `/home` | 查看个人首页概览、快速访问空间/面板/任务 |
| 空间 | `/spaces` | 查看空间列表，点击空间进入空间详情 |
| 所有工作 | `/all-work` | 管理当前用户可见工作项，可筛选和切换视图 |
| 仪表板 | `/dashboards` | 查看个人任务、项目动态和反馈入口 |
| 通知 | `/notifications` | 查看系统通知，并可切换应用主题 |

点击当前 Tab 时会回到该分支初始页面；点击其他 Tab 时切换到对应页面并保留其他 Tab 的历史状态。

## 5. 主页交互

主页对应业务流程中的“项目与任务管理”和“AI 辅助摘要入口”。

主要区域：

| 区域 | 已实现交互 | 后端依赖 |
| --- | --- | --- |
| 用户头像 | 点击进入账户中心 | 用户资料接口 |
| 创建按钮 | 弹出“创建工作项接口已预留”提示 | 创建工作项接口 |
| 搜索框 | UI 已完成，尚未提交查询 | 全局搜索接口 |
| 今日概述 | 支持折叠/展开、复制、点赞、点踩、更多 | AI 摘要、反馈、动态接口 |
| 快速访问 | 支持折叠/展开；有路由时进入详情，无路由时提示预留入口 | 快捷入口配置接口 |
| 最近项目 | 支持折叠/展开；点击项目提示将打开详情 | 最近访问、工作项详情接口 |

主页现有状态：

- `_overviewExpanded` 控制今日概述折叠。
- `_quickAccessExpanded` 控制快速访问折叠。
- `_recentProjectsExpanded` 控制最近项目折叠。
- 折叠动画使用 `AnimatedSwitcher` + `SizeTransition` + `FadeTransition`。

## 6. 空间与空间详情交互

### 空间列表

空间页用于承载业务流程中的“工作区与群组管理”。

| 操作 | 当前行为 | 后端接口 |
| --- | --- | --- |
| 点击头像 | 进入账户中心 | 用户资料接口 |
| 搜索空间 | 显示预留提示 | 空间搜索接口 |
| 创建空间 | 显示预留提示 | 创建空间接口 |
| 点击空间卡片 | 跳转 `/space-details` | 空间详情接口 |

### 空间详情

空间详情使用顶部 Tab，包含五个子视图。

| Tab | 功能 | 当前交互 |
| --- | --- | --- |
| 摘要 | 项目指标、状态概览、优先级细分 | 点击状态项提示按状态筛选 |
| 面板 | 看板视图 | 空状态，点击“查看待办事项列表”跳到待办 Tab |
| 日历 | 日期视图与筛选 | 可切换筛选项和选中日期 |
| 表单 | 表单占位 | 仅占位展示 |
| 待办事项列表 | Sprint/待办分组与任务 | 可展开/收起分组，点击创建提示接口预留 |

空间详情顶部操作：

- 返回按钮返回上一页。
- 筛选按钮预留空间筛选接口。
- 更多按钮预留空间管理接口。

## 7. 所有工作交互

所有工作页对应任务查询和个人工作台。

| 操作 | 当前行为 | 后端接口 |
| --- | --- | --- |
| 头像 | 进入账户中心 | 用户资料接口 |
| 搜索 | 显示预留提示 | 工作项搜索接口 |
| 创建 | 显示预留提示 | 创建工作项接口 |
| 筛选器 | 打开底部筛选弹窗 | 筛选器列表、保存筛选器接口 |
| 选择筛选器 | 更新本地 `_selectedFilter` | 工作项列表查询接口 |
| 列表/网格切换 | 更新本地 `_viewMode` | 无需后端，属于前端展示状态 |
| 点击工作项 | 显示将打开详情提示 | 工作项详情接口 |

筛选弹窗包括：

- 最近的筛选器。
- 默认筛选器。
- 创建筛选器入口。
- 点击某个筛选器后 `Navigator.pop(filter)`，父页面更新选中筛选器。

## 8. 仪表板交互

仪表板对应业务流程中的“报表分析”和“项目洞察”。

| 模块 | 当前交互 | 后端接口 |
| --- | --- | --- |
| 默认仪表板切换 | 点击提示“仪表板切换接口已预留” | 仪表板列表和切换接口 |
| 分配给我的工作项 | 点击提示打开工作项 | 我的工作项接口 |
| 活动流 | 点击提示打开活动详情 | 活动日志接口 |
| 反馈卡片 | 点击提示反馈接口预留 | 反馈提交接口 |

仪表板需要后端聚合任务、工时、状态、成员、通知、AI 分析结果和报表快照。

## 9. 通知与账户交互

### 通知页

| 操作 | 当前行为 | 后端接口 |
| --- | --- | --- |
| 点击头像 | 进入账户中心 | 用户资料接口 |
| 切换主题 | 全局切换浅色/深色主题 | 可选：用户偏好保存接口 |
| 点击通知 | 显示详情入口预留提示 | 通知详情、已读接口 |

主题切换使用 `ThemeControllerScope.of(context).toggle()`，当前只保存在内存中。

### 账户中心

账户中心分为：

- 用户资料卡片。
- 工作区：邀请人员访问工作区。
- 首选项：通知设置、设置。
- 关于：提供反馈、评价我们、更多应用。
- 退出登录。

当前所有账户操作均为预留入口，后端需要提供用户、工作区成员、通知偏好、反馈和认证退出接口。

## 10. 前端数据模型

当前演示数据模型位于 `jira_models.dart`。

| 模型 | 字段 | 对应后端实体 |
| --- | --- | --- |
| `QuickAccessItem` | 标题、副标题、图标、颜色、徽标、路由 | 快捷入口 |
| `IssueSummary` | 标题、编号、副标题、状态、经办人 | 工作项 |
| `JiraSpace` | 名称、空间 Key | 空间/项目 |
| `SpaceSummaryMetric` | 指标标题、数值、图标、颜色、强调文本 | 空间统计 |
| `DashboardActivityItem` | 动态内容、关联工作项、时间 | 活动日志 |
| `NotificationItem` | 标题、描述 | 通知 |
| `FilterItem` | 标题、图标 | 筛选器 |
| `BacklogGroup` | 分组标题、数量统计、工作项列表 | Sprint/待办分组 |

## 11. 前后端对接建议

前端接入真实后端时，建议按以下顺序替换演示数据：

1. 用户与认证：登录态、用户资料、退出登录。
2. 空间与工作项：空间列表、工作项列表、工作项详情、创建工作项。
3. 筛选器：默认筛选器、用户自定义筛选器、筛选查询。
4. 空间详情：摘要指标、状态分布、优先级分布、待办分组、日历到期项。
5. 通知与动态：通知列表、已读状态、活动日志。
6. AI 与报表：今日概述、AI 问答、复盘报告、绩效分析。

建议新增前端 API 层：

```text
lib/
├── services/
│   ├── api_client.dart
│   ├── auth_api.dart
│   ├── spaces_api.dart
│   ├── issues_api.dart
│   ├── dashboards_api.dart
│   ├── notifications_api.dart
│   └── ai_api.dart
└── viewmodels/
    ├── issue_models.dart
    ├── space_models.dart
    └── dashboard_models.dart
```

统一错误处理：

- 网络异常：展示“网络连接异常，请稍后重试”。
- 权限异常：展示“无权限访问该资源”并引导返回。
- 参数异常：展示后端返回的字段级错误。
- 服务异常：展示通用错误，并记录日志。
